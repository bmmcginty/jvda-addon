Quick start

  • Press Numpad Minus for the JAWS Cursor. Press it again quickly for the independent Invisible Cursor.
  • Press Numpad Plus to return to the PC Cursor.
  • On Laptop layout, use NVDA+P for the JAWS Cursor and NVDA+Semicolon for the PC Cursor.
  • Press NVDA+` to disable every JVDA keyboard command. The same command remains available to turn JVDA commands back on.
  • Press Ctrl+Shift+NVDA+F2 for the searchable command compatibility list.
  • Press NVDA+1 for JAWS-oriented Input Help.

Cursors and routing

The JAWS Cursor reviews screen text and can move the mouse. The Invisible Cursor keeps an independent review position and never moves the physical mouse. Shift+Numpad Plus activates Touch Cursor traversal. Windows+NVDA+Minus activates Object Navigation.

NVDA+Numpad Minus moves the JAWS or Invisible Cursor to the PC Cursor. NVDA+Numpad Plus routes the PC Cursor to the review cursor and returns to PC mode. NVDA+R cycles cursor restrictions. The JAWS Cursor remains independent of PC focus and caret changes by default; optional tethering is available in settings.

Web browsing

NVDA Browse Mode is the JAWS Virtual Cursor equivalent. Focus Mode is the JAWS PC Cursor or Forms Mode equivalent. Use NVDA+Z to switch modes.

  • Use H or Shift+H for headings, T or Shift+T for tables, F or Shift+F for form controls, and K or Shift+K for links.
  • By default, JVDA makes Shift+H speak only the destination heading rather than ancestor heading text exposed by applications such as Discord.
  • Press Enter or Space to interact with a control. Press Escape or NVDA+Z to return to Browse Mode.
  • Optional JAWS quick-key overrides add JAWS-compatible meanings for A, O, Z, and the temporary PlaceMarker commands.

Layered JAWSKey+Space commands

Press JAWSKey+Space, then one more key, the way JAWS layers work. Two rising tones mean the layer is open. The basic layer closes after one command. Some keys open a sublayer instead, and a sublayer stays open so that its keys can be pressed repeatedly. Escape, Space, Tab, Enter, two seconds without a key press, moving the mouse, or changing window all close the layer.

Two falling tones mean the layer has closed with nothing else to say, after Escape or a timeout. A command that speaks its result, or opens a window, plays no tone: hearing “Audio ducking on” already tells you the layer has ended.

In the basic layer, C shows the clipboard text, D turns audio ducking on or off, F11 or Print Screen turns the screen shade on or off, J opens the command compatibility list, L turns JVDA's keyboard commands off or on, S mutes or unmutes speech, and Shift+S switches speech on demand on or off. V opens the volume layer and T opens the table layer.

In the volume layer, J adjusts the synthesizer volume, B sets the sound balance between NVDA and other applications, and C moves through the audio output devices. In the table layer, the arrow keys move a cell at a time and the layer stays open until it is closed.

JVDA offers only the sublayers it can actually run. JAWS's braille and text viewer, mouse echo, Face in View, OCR, Picture Smart and Skype layers, and the volume layer's system volume sublayer, report “command invalid” when their key is pressed. They do not open, because a layer in which every key answered “command invalid” would tell the user nothing.

Press question mark inside any layer to list that layer's keys. A key with a JAWS command JVDA cannot provide reports “command invalid”; a key with no JAWS command reports “command unassigned”. Both end the layer. NVDA's Input Help cannot describe layer keys, because JVDA dispatches them itself.

The layer takes NVDA+Space, which is NVDA's own browse and focus mode toggle. JAWSKey+Z does the same job and is the JAWS command for it. Unchecking “JAWSKey+Space layer commands” in JVDA settings gives NVDA+Space back at once.

Settings

Open NVDA menu, Preferences, Settings, JVDA. The panel controls repeated-symbol limits, mouse movement, JAWS-to-PC tethering, NVDA modifier double-taps, CapsLock double-tap, blank-line handling, table coordinate speech, autocomplete and status announcements, Alt+Tab position speech, list-view separators, previous-heading speech, optional JAWS web quick keys, the JAWSKey+Space layer, the JAWS-only keyboard, and debug logging.

“Ignore NVDA's own key commands (JAWS-only keyboard)” is off by default. When it is on, an NVDA-modified key JVDA has not given a JAWS command to is blocked and JVDA says “unavailable jaws command” instead of letting NVDA answer it. Ordinary typing and Control, Alt, Shift and Windows commands are untouched. JAWSKey+grave, JAWSKey+F4, JAWSKey+N and JAWSKey+1 always keep working, so NVDA is always reachable.

By default, JVDA prevents a rapid double-tap of CapsLock, Numpad Insert, or dedicated Insert from passing the bare key to the focused application. Uncheck “Prevent NVDA modifier keys from passing through on double-tap” to restore NVDA's native behavior. The separate CapsLock option continues to provide JAWS-style CapsLock toggling.

Options explicitly labelled “requires restart” take effect after NVDA restarts. Other options, including modifier double-tap suppression, the JAWSKey+Space layer and the JAWS-only keyboard, apply immediately.

Classic Winamp

When focus is in classic Winamp, JVDA provides these JAWS-compatible reports:

CommandReport
Alt+Shift+TElapsed time
Control+Shift+TRemaining time
Control+NVDA+TTotal track length
Alt+Control+TCurrent track title
Shift+NVDA+TTitle, length, sample rate, bit rate, and channel count

Live streams may not expose a total length. This support targets Winamp's classic “Winamp v1.x” window and preserves NVDA's playlist, shuffle, and repeat support.

Troubleshooting

JVDA keys interfere with an application
Press NVDA+` to disable JVDA keyboard commands. Press it again to restore them.
Arrow keys do not edit or move the caret
Press Numpad Plus to return to the PC Cursor. Laptop users can press NVDA+Semicolon.
Letters type instead of navigating a web page
Press Escape or NVDA+Z to enter Browse Mode. Use Focus Mode when an interactive web application needs unmodified letters.
A changed setting does not work
Restart NVDA if the setting is labelled “requires restart.”
A command still fails
Confirm NVDA's Desktop or Laptop layout, check Num Lock and numpad availability, and test with other add-ons disabled. Restart NVDA with add-ons disabled if necessary.

Known limitations

  • Application accessibility providers determine which text, objects, headings, and tables are available. Results can differ in browsers, PDFs, Discord, terminals, and custom controls.
  • JVDA provides practical NVDA equivalents for many JAWS commands. It is not a JAWS scripting runtime and does not implement every JAWS feature.
  • Some commands intentionally remain native NVDA commands. The searchable compatibility list identifies equivalent, approximate, and unavailable mappings.
  • JVDA requires NVDA 2026.1 or later and has been tested through NVDA 2026.2.0.

Support

Email help@effortlessvi.com. Include:

  • JVDA, NVDA, and Windows versions;
  • the affected application and browser, if applicable;
  • exact keystrokes and steps to reproduce the problem;
  • what you expected and what NVDA spoke; and
  • whether it occurs with other add-ons disabled.

Ctrl+Shift+NVDA+F1 displays non-sensitive JVDA cursor diagnostics without document text. Review diagnostics and NVDA logs before sharing them because environmental or third-party information may still be present. JVDA never sends support information automatically.

Installation and removal

Install the .nvda-addon package through NVDA's Add-on Store. Restart NVDA when prompted. To temporarily stop JVDA without changing its installation, press NVDA+`. To disable, enable, update, or remove JVDA, open NVDA menu, Tools, Add-on Store, Installed add-ons.

If NVDA becomes unusable, choose NVDA menu, Tools, Restart with add-ons disabled.

Accessibility and privacy

JVDA dialogs and settings use standard keyboard-accessible NVDA and wxPython controls with labels, keyboard focus, and standard Close or Escape behavior. Report an inaccessible workflow to help@effortlessvi.com.

JVDA does not transmit telemetry, support requests, diagnostics, or logs. Debug logging is optional and disabled by default.
